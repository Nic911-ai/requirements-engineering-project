1. Requirement Used
- The system shall allow a user to view equipment availability for selected date.
- Students may need to view equipment availability.
- Students may need to create bookings.
- Equipment technicians may need to view equipment availability.
- Equipment technicians need to record equipment returns.

2. Actors
Student - Uses system to view available equipment and create bookings.
Equipment Technician - Uses the system to view equipment availability and record equipment returns.
Equipment Manager - Manage equipment

3. Uses Cases
View Equipment Availability - Allows user to check which equipment is available for selected date.
Create booking - Allows a student to make a booking for equipment.
Cancel Booking - Allow user to cancel an existing booking.
Record Equipment Return - Allows an equipment technician to record that equipment has been returned.
